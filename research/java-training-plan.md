## Воспроизведение первого импорта

Разбиение на 14 обучающих, 4 валидационных и 6 итоговых задач зафиксировано в [exercism-java-split.csv](../datasets/exercism-java-split.csv). Задачи группируются по семействам до импорта.

1. Поместить чистую копию [Exercism Java на зафиксированной ревизии](https://github.com/exercism/java/tree/84065eb95937f00e029fc690dbea7dd970439abf) в `build/exercism-java`.
2. Поместить JAR JUnit Platform Console Standalone 1.10.0 и AssertJ Core 3.25.1 в `build/exercism-libs`. Импорт проверяет их SHA-256. [JUnit JAR](https://maven-central.storage-download.googleapis.com/maven2/org/junit/platform/junit-platform-console-standalone/1.10.0/junit-platform-console-standalone-1.10.0.jar) · [AssertJ JAR](https://maven-central.storage-download.googleapis.com/maven2/org/assertj/assertj-core/3.25.1/assertj-core-3.25.1.jar).
3. Из корня AMC с JDK 27 в `JAVA_HOME` и локальным Linux-образом `eclipse-temurin:21-jdk` выполнить команды ниже.

```powershell
.\scripts\build.ps1
.\scripts\import-exercism.ps1
$java = "$env:JAVA_HOME\bin\java.exe"
foreach ($split in 'train', 'validation', 'test') {
    & $java -cp build/classes dev.amc.benchmark.JavaProgramBenchmark build/java-exercism --reference $split
}
& $java -cp build/classes dev.amc.benchmark.JavaProgramBenchmark build/java-exercism --initial validation
& $java -cp build/classes dev.amc.training.TrainPrograms build/java-exercism results/java-exercism.bin 100 42
& $java -cp build/classes dev.amc.benchmark.JavaProgramBenchmark build/java-exercism results/java-exercism.bin validation
```

Тесты запускаются без изменений исходников. JUnit включает тесты, которые Exercism помечает `@Disabled` для пошагового прохождения упражнения. Итоговое разбиение предназначено для сравнения после настройки модели на валидации. [Параметр JUnit](https://docs.junit.org/5.10.0/user-guide/#extensions-conditions-deactivation).
